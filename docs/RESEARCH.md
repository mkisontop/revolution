# Revolution — Research Appendix (July 2026)

Condensed findings from four parallel research sweeps (agent harnesses; Windows capture/overlay/anti-cheat; voice pipeline; realtime-vision patterns & memory) plus user-contributed prior-art research. Load-bearing claims carry sources; numbers flagged *(est.)* are triangulated estimates to be re-measured in Phase 1.

---

## 1. Agent harnesses — what "Hermes" is and where a harness belongs

**Hermes Agent** (`NousResearch/hermes-agent`) is Nous Research's open-source, model-agnostic agent harness — launched Feb 25 2026, MIT, Windows-native, ~221K GitHub stars by late July 2026, v0.19 "Quicksilver". Ships: 60+ tools, parallel subagents, MCP client, three-layer memory (curated persistent memory + FTS5 session search + Markdown "skills" with a self-improvement loop), PTT voice with streaming TTS, vision input, and documented embedding paths (`hermes acp` stdio JSON-RPC, WebSocket/HTTP gateway, in-process Python). Caveats: 0.x velocity with breaking changes and 25K+ open issues; ~0.9s *cold* submit-to-dispatch (Nous's own v0.19 number) plus a heavy skills/memory system prompt; a dedicated low-latency duplex voice mode is still an open feature request (#35750). Nous's own docs steer the harness toward frontier cloud models for agentic loops (Hermes-the-model is tuned for chat, not rapid tool-calling).

**Conclusion:** no full harness (Hermes *or* Claude Agent SDK) fits a sub-2s voice hot path; both fit the async deep-research lane. Hot path = hand-rolled direct-API streaming loop (~150–300 LoC the app controls); deep lane = Claude Agent SDK (default, tightest Claude integration) or Hermes Agent sidecar (MIT, model-agnostic, memory/skills for free — the legitimate home for the user's Hermes interest). OpenAI Agents SDK notable for `RealtimeAgent` (sub-1s speech-to-speech on gpt-realtime-2.1 with image input) — adopted in our design as optional Pipeline B rather than as the core harness.

Sources: [hermes-agent repo](https://github.com/nousresearch/hermes-agent) · [official docs](https://hermes-agent.nousresearch.com/docs/) · [programmatic integration](https://hermes-agent.nousresearch.com/docs/developer-guide/programmatic-integration) · [TechCrunch on Nous funding](https://techcrunch.com/2026/07/13/hermes-agent-maker-nous-research-in-talks-for-new-funding-at-1-5b-valuation/) · [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) · [OpenAI voice agents](https://openai.github.io/openai-agents-js/guides/voice-agents/)

## 2. Windows 11 capture, OCR, overlay, anti-cheat

- **Capture: Windows.Graphics.Capture (WGC)** — modern path, event-driven (frames only on change), cross-GPU, what OBS recommends; DXGI Desktop Duplication is legacy and unreliable under 24H2 MPO. 24H2 adds `MinUpdateInterval`, `DirtyRegionMode`, and removable yellow border (`IsBorderRequired=false` after `RequestAccessAsync`). Rust: [`windows-capture`](https://github.com/NiiightmareXD/windows-capture) v2 (active, MIT, ~587K downloads). Overhead at ~1fps ≈ zero *(practitioner consensus; no formal benchmark — Phase 1 verifies)*; 720p JPEG via libjpeg-turbo ≈ 3–8ms/core *(est.)*.
- **Exclusive fullscreen** is effectively obsolete (flip-model/FSO); overlays require borderless anyway → first-run "use borderless" tip. Capture the **game HWND** so the pet is never in frame — avoiding `WDA_EXCLUDEFROMCAPTURE`, which is a documented cheat "streamproof" signature that at least one anti-cheat enumerates.
- **OCR:** `Windows.Media.Ocr` ships in every Win11, offline, fast (~tens of ms *(est.)*), mediocre on stylized fonts — perfect as a trigger/grounding channel, not ground truth. Officially needs package identity (ship MSIX/sparse identity). OneOCR (Snipping Tool engine) is better but legally gray (extracted DLL). Copilot+ `TextRecognizer` can't be assumed on gamer hardware in 2026.
- **Overlay shell: Tauri v2** — production gaming-overlay precedent measured 14MB main-process RAM, <1% idle CPU ([Manasight](https://blog.manasight.gg/why-i-chose-tauri-v2-for-a-desktop-overlay/)); typical totals 30–50MB vs Electron 150–300MB. Known-and-solved gotchas: per-region click-through via ~60Hz cursor poll toggling `set_ignore_cursor_events` (no Electron-style `forward:true` — [#6164](https://github.com/tauri-apps/tauri/issues/6164)), `WS_EX_NOACTIVATE` against focus steal, global-shortcut plugin fails in some DirectInput titles ([#7318](https://github.com/tauri-apps/tauri/issues/7318)) → **low-level `WH_KEYBOARD_LL` hook** is the robust PTT path (also gives down/up for hold-to-talk). Reference projects: [Overlayed](https://overlayed.dev/) (Tauri Discord overlay), [VPet](https://github.com/LorisYounger/VPet) (WPF pet, animation state machines).
- **Anti-cheat:** passive out-of-process capture + a plain always-on-top window + zero injection/memory/input is the tolerated envelope (BattlEye statement; OBS precedent; Riot Vanguard dev FAQ — what's banned is memory reading and injected overlays; Microsoft Gaming Copilot and NVIDIA G-Assist ship this exact shape at scale). FACEIT is the most aggressive client → explicit test-matrix item with auto-hide fallback.

Sources: [OBS on WGC vs DXGI](https://obsproject.com/forum/threads/windows-graphics-capture-vs-dxgi-desktop-duplication.149320/) · [GraphicsCaptureSession 26100](https://learn.microsoft.com/en-us/uwp/api/windows.graphics.capture.graphicscapturesession?view=winrt-26100) · [SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity) · [Vanguard dev FAQ](https://www.riotgames.com/en/DevRel/vanguard-faq) · [TAC reversing (WDA enumeration)](https://ssno.cc/posts/reversing-tac-1-4-2025/) · [G-Assist](https://www.nvidia.com/en-us/geforce/news/g-assist-ai-companion-for-rtx-ai-pcs/) · [Gaming Copilot screenshots](https://www.tomshardware.com/video-games/pc-gaming/microsoft-says-gaming-copilot-uses-screenshots-to-understand-in-game-events-not-for-training-ai-models-optional-feature-can-be-turned-off-but-not-easily-uninstalled)

## 3. Voice pipeline

- **STT (PTT-shaped):** stream during hold, force-finalize on release. Deepgram Nova-3 (`Finalize`/`KeepAlive`, ~$0.0077/min streamed, final in ~100–300ms) or AssemblyAI Universal-Streaming (`ForceEndpoint`, $0.15/session-hr). Simple v0: Groq Whisper large-v3-turbo batch POST (~200–350ms round trip, $0.04/audio-hr). Local CPU fallback: **Moonshine v2** (streaming encoder; ~150–300ms finalize small model *(vendor paper)*; verify license) or whisper.cpp base.en (~0.3–0.9s under game load *(est.)*).
- **TTS:** Cartesia Sonic-3/Turbo (~40–90ms model-side TTFA; *continuations* designed for LLM token streaming) or ElevenLabs Flash v2.5 (~75ms claim; best voice library; use the websocket — 1k-char minimum per HTTP call). Local fallback: Kokoro-82M (Apache, RTF ~0.2–0.5 CPU). Vendor TTFA figures exclude network — measure client-side.
- **Pipeline pattern:** sentence-chunked LLM→TTS overlap (play sentence 1 while sentence 3 generates) is standard 2026 practice (LiveKit/Pipecat); PTT makes barge-in deterministic (<60ms flush target) and eliminates echo (never record while speaking).
- **Ducking:** `IAudioSessionManager2` → game session by PID → `ISimpleAudioVolume::SetMasterVolume` (Discord's mechanism). WASAPI-exclusive games bypass it (rare).
- **Measured budget, release → first word (all-cloud):** STT 100–300ms + LLM leg 550–1,150ms + TTS 100–250ms + output 30–60ms ≈ **0.8–1.75s p50, p95 risk ~2.3s**. Dominant/softest number is vision-LLM TTFT — no public image-TTFT benchmark isolates it; mitigations: key-down pre-capture/pre-upload, ~1024px frames, cached prefix, short-first-sentence prompting.
- **Speech-to-speech alternative:** OpenAI gpt-realtime-2.1 sessions accept image input + tools, sub-1s voice-to-voice, ≈$0.06/min audio in + $0.24/min out (mini ≈ ⅓) — our Pipeline B.

Sources: [Deepgram Finalize](https://developers.deepgram.com/docs/finalize) · [AssemblyAI Universal-Streaming](https://www.assemblyai.com/docs/streaming/universal-streaming) · [Groq Whisper turbo](https://groq.com/blog/whisper-large-v3-turbo-now-available-on-groq-combining-speed-quality-for-speech-recognition) · [Moonshine v2 paper](https://arxiv.org/html/2602.12241) · [ElevenLabs stream-input](https://elevenlabs.io/docs/api-reference/text-to-speech/v-1-text-to-speech-voice-id-stream-input) · [Cartesia continuations](https://docs.cartesia.ai/build-with-cartesia/capability-guides/stream-inputs-using-continuations) · [Kokoro CPU benchmark](https://gist.github.com/efemaer/23d9a3b949b751dde315192b4dcf0653) · [Windows ducking](https://learn.microsoft.com/en-us/windows/win32/api/audiopolicy/nf-audiopolicy-iaudiosessionmanager-getsimpleaudiovolume) · [LiveKit pipeline architecture](https://livekit.com/blog/voice-agent-architecture-stt-llm-tts-pipelines-explained) · [gpt-realtime](https://openai.com/index/introducing-gpt-realtime/)

## 4. Realtime screen-watching patterns & memory

- **Nobody streams continuous video to a frontier cloud LLM.** Shipping products use on-demand snapshots (Gaming Copilot: screenshots when you ask; Razer Ava: burst screenshots on trigger — runs on xAI Grok), local-only continuous capture (MS Recall: ~3–5s cadence, all local), or bounded 1fps sessions (Gemini Live: 258 tokens/frame — economically unviable for ambient hours). Our ring-buffer + change-gate + ask-time-burst design matches the category consensus; [Screenpipe](https://github.com/screenpipe/screenpipe) (Rust, event-driven capture with ~0.5fps idle floor) is the best open-source reference for capture gating.
- **Change detection:** dHash (9×8 grayscale, 64-bit, Hamming) + histogram fallback; ≪0.1% of a core at 1–4Hz on 320×180 thumbnails; tune thresholds per genre (HUD-heavy = constant small deltas) + min-interval + 15–30s heartbeat. PySceneDetect benchmarks: hash/histogram detectors process thousands of fps on CPU.
- **Prompt/caching mechanics:** strict prefix match; append-only history; byte-stable image encoding (a re-encoded JPEG silently invalidates); images only in newest 2–3 turns; intermediate cache breakpoints every ~15 blocks (20-block lookback limit); frozen system prompt; volatile state injected late (`role:"system"` mid-messages on supporting Claude models); compaction at ~30–50K tokens or ~10 images → old frames become text placeholders, summary written to memory (one deliberate cache rebuild). Claude image cost ≈ (w×h)/750 → ~1.2K tokens at 1280×720. Cache minimums vary by model (Opus 5: 512 tokens; Haiku 4.5: 4096 — the lean ambient prompt may simply not cache, acceptable at its price). OpenAI/Gemini cache automatically with the same stable-prefix layout.
- **Memory:** SQLite + FTS5 + small ONNX embeddings (bge-small-en-v1.5 int8 via fastembed; 384-d; brute-force cosine fine to ~100K rows; `sqlite-vec` escape hatch — note it's brute-force too, no ANN as of v0.1.x). Architecture stolen from the best of MemGPT/Letta (always-in-context **profile card** as editable core memory + sleep-time consolidation), Mem0 (**ADD/UPDATE/DELETE/NOOP gate** against top-k similar facts — prevents "level 12/30/45" clutter), LangMem (semantic/episodic/procedural split + background writer). Anthropic's `memory_20250818` file-based tool is a valid zero-schema alternative when the brain is Claude.
- **Game identity:** foreground exe → Discord detectable-games DB (`/api/v9/applications/detectable`, unofficial, cache it) → Steam `appmanifest_*.acf` (the `RunningAppID` registry key is dead) → title fuzzy match. Knowledge: IGDB (free Twitch OAuth, 4 req/s), Steam appdetails, PCGamingWiki Cargo, Fandom/wiki.gg MediaWiki APIs; high-fidelity local overrides where games offer them (LoL `localhost:2999` Live Client API, CS2/Dota 2 GSI). Privacy: the Gaming Copilot Oct 2025 backlash (auto-screenshots + default-on training toggle) defines the trust bar — visible indicator, local-only buffer, upload-on-ask.

### Questie.ai deep-dive (verified July 2026)

The category leader (~20–25K claimed users, ~1 year old) — and structurally different from Revolution: it's a **browser web app** (screenshare a game window into a tab; no desktop app, no overlay, no pet, mobile is a web wrapper). Verified facts that shape our design:

- **Stack & economics:** user-selectable models (25+), but their own prompt guide recommends Gemini Flash-class as default ("best all-around" / Flash-Lite "for lowest latency") — i.e. the shipping default is exactly the cheap-fast-VLM tier our `qa` role targets. Pricing $19.99/mo ≈ 25hrs → **$0.50–0.80/hr retail**; inference-side cost plausibly $0.10–0.30/hr. Revolution's BYO-key model undercuts this structurally — "**your key, your cost, no credit meter**" is the positioning (credit anxiety is their most-quoted complaint).
- **Their best design work — the cadence contract** (quoted from their per-game pages): feedback lands "between rounds and respawns, after a death or failed play, during repositioning or downtime, in natural pauses — not over active fights." Plus genre-adaptive attention (tactical FPS → economy/positioning/rotations; RPG → builds/navigation) with zero configuration, and a concrete trigger taxonomy (wasted ult in a won round, no-utility corner push, spike timing, death postmortems). **Adopted** into our hype-mode spec and ambient system prompt.
- **Their persona recipe** (their prompting guide): hard cap 1–2 sentences, max one question, "react before advising," ban disclaimers and bullet lists in voice. **Adopted** into `default_system_core()`. The press "magic moments" are all personality — roasts, in-jokes, callbacks (404 Media's Tarkov test: "almost as good as playing with my friends") — not tips. Personality presets with backstories are the emotional product.
- **Memory:** Zep graph memory ("running jokes, builds, mistakes, ongoing storylines") — our SQLite design covers the same targets with `kind`-tagged facts; graph memory (Zep/Graphiti) is a Phase 3+ consideration, not needed at v1 scale.
- **Their failure modes = our requirements:** (1) confidently-wrong game mechanics ("sycophantic praise while being factually incorrect" — a reviewer's verdict was "not worth it for precise coaching") → our web-search grounding + "never bluff mechanics" prompt rule; (2) latency overclaiming (marketing "sub-300ms" vs observed "within seconds") → we publish measured numbers from the debug overlay; (3) mid-session memory resets → our append-only transcript + explicit compaction; (4) bad default TTS voice → first-touch voice quality is a launch checklist item; (5) anti-cheat silence (never addressed publicly) → our published envelope is a trust feature.
- Sources: [questie.ai](https://www.questie.ai/) ([pricing](https://www.questie.ai/pricing) · [prompting guide](https://www.questie.ai/prompting) · [Valorant page](https://www.questie.ai/gaming-ai/valorant)) · [404 Media firsthand](https://www.404media.co/i-replaced-my-friends-with-ai-because-they-wont-play-tarkov-with-me/) · [roborhythms review](https://www.roborhythms.com/questie-ai-review/) · [automateed review](https://www.automateed.com/questie-ai-review) · [Sidekick on Steam](https://store.steampowered.com/app/3992240/Sidekick_AI/) · [Wezzly](https://github.com/idobaibai-wezzly/wezzly-companion-public)

Community signal (Reddit/X/forums, per user's survey + review sweep): the "friend who's actually watching" feeling is the valued core, memory + personality consistency is praised when it works, hotkey/voice activation feels natural; recurring complaints are cloud-vision cost/lag, accuracy on fast action, and privacy of continuous capture — all directly addressed by our change-gated local buffer, upload-on-ask default, BYO fast models, and per-game memory.

**Differentiation thesis:** none of the surveyed products combines (a) a native low-overhead overlay + PTT (no browser-tab taxes), (b) BYO provider/key with per-role routing (no credit meter), (c) a research-grade deep lane with native web search (kills confidently-wrong coaching), (d) local-only memory with a per-game profile card, and (e) a published anti-cheat/privacy envelope. That combination is Revolution's slot.
